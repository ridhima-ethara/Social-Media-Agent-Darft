# Jerry — Analytics Agent · Measurement against our own baseline

- **Id**: `analytics`
- **Stage**: `learn`
- **Hands off to**: `learning`
- **Skills**: 8
- **Handlers**: `server/src/agents/analytics/handlers.ts`

Ingests platform metrics and judges every post against this account’s own trailing baseline, never an industry benchmark. A metric that has not been reported yet is excluded, never counted as zero. Explains why a post performed as it did, and composes the monthly report.

## Skills

### `analytics.metrics.ingest`

Pulls the current figures for every published post and writes a new metrics row per pull, never overwriting the last one.

| Knob | Default | Description |
|---|---|---|
| `maxPosts` | `60` | How many recent posts to refresh in one pass. |
| `appendOnly` | `true` | On, each pull adds a row so the history of a post’s performance survives. Off would destroy the trend. |

### `analytics.metrics.reconcile`

Marks which periods the platform has actually reported. A metric that has not been reported is excluded, never counted as zero.

| Knob | Default | Description |
|---|---|---|
| `excludeUnreported` | `true` | On, an unreported month is left out of every average. Off would drag every baseline toward zero and quietly corrupt the comparisons. |
| `reportingLagDays` | `3` | How long after a period ends the platform is expected to have reported it. |

### `analytics.baseline.compute`

Builds the trailing baseline from this account’s own history. Never an industry benchmark — that is invariant 24.

| Knob | Default | Description |
|---|---|---|
| `windowPeriods` | `4` | How many prior periods form the baseline. Four weeks is responsive; twelve is stable and slow to react. |
| `measure` | `Mean` | Median resists a single viral post distorting the baseline. Mean reacts faster to a genuine step change. |
| `minSamples` | `2` | How many reported periods are needed before a baseline is offered at all. |

### `analytics.sentiment.classify`

Reads the response to a post and classifies how it landed, so engagement volume is not mistaken for approval.

| Knob | Default | Description |
|---|---|---|
| `positiveThreshold` | `60` | How favourable the response must be to count as positive. |
| `negativeThreshold` | `30` | Below this the response is classified negative and flagged for a human read. |

### `analytics.period.compare`

Compares a period against the one before it and against the trailing baseline, stating the change and where it is concentrated.

| Knob | Default | Description |
|---|---|---|
| `materialChange` | `10` | How large a movement must be before it is worth mentioning. Below this it is noise. |
| `attributeChange` | `true` | On, the comparison says where the movement came from — follower against non-follower reach, for instance — rather than only that it happened. |

### `analytics.post.explain`

Says why a post performed as it did, citing its own figures against this account’s baseline and naming the format, slot and topic that contributed.

| Knob | Default | Description |
|---|---|---|
| `maxChars` | `320` | The ceiling on a post explanation. |
| `includeRecommendation` | `true` | On, the explanation ends with the one thing to do differently next time. |
| `neverUseIndustryBenchmark` | `true` | This is invariant 24 and should stay on. An industry benchmark we did not measure is not evidence. |

### `analytics.report.compose`

Assembles the month into headline figures, the shape of the period and what the numbers say.

| Knob | Default | Description |
|---|---|---|
| `topPosts` | `3` | How many individual posts the report calls out. |
| `includeUnreported` | `true` | On, the report states plainly that a platform has not reported yet rather than omitting it silently. |

### `analytics.export.build`

Produces the CSV or JSON of any analytics view, carrying the same figures the screen shows.

| Knob | Default | Description |
|---|---|---|
| `format` | `Both` | Which formats to offer in the download menu. |
| `includeDaily` | `true` | On, exports carry the day-by-day figures as well as the monthly totals. |
