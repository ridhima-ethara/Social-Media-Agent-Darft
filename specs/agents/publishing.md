# Mickey — Publishing Agent · The one irreversible act

- **Id**: `publishing`
- **Stage**: `ship`
- **Hands off to**: `analytics`
- **Skills**: 4
- **Handlers**: `server/src/agents/publishing/handlers.ts`

Validates the format against the platform, uploads the media, dispatches the post and records a receipt. Demo mode fabricates ids; live mode requires real credentials. The mode is recorded permanently on every receipt and demo and live are never mixed.

## Skills

### `publishing.format.validate`

Checks the caption length, the hashtag count, the canvas and the alt text against the target platform before anything is dispatched.

| Knob | Default | Description |
|---|---|---|
| `blockOnFailure` | `true` | On, a format failure stops the publish. This should stay on: the platform will reject it anyway, and later. |
| `requireAltText` | `true` | On, an asset without alt text cannot be published. This is invariant 23. |

### `publishing.media.upload`

Uploads the creative to the platform and holds the returned handle for the post call.

| Knob | Default | Description |
|---|---|---|
| `timeoutMs` | `45000` | How long an upload may take before it is abandoned. |
| `retries` | `2` | How many times a failed upload is retried. |

### `publishing.post.dispatch`

The irreversible act. Sends the post to the platform through the demo or live adapter, and the two are never mixed.

| Knob | Default | Description |
|---|---|---|
| `timeoutMs` | `60000` | How long the platform has to accept the post before the attempt is treated as failed. |
| `recordModeOnReceipt` | `true` | On, every receipt permanently states whether it was demo or live. This should never be off — it is how you tell a real post from a simulated one a year later. |

### `publishing.receipt.record`

Writes the published row, its append-only history, and the lineage edge back to the idea it came from.

| Knob | Default | Description |
|---|---|---|
| `seedFirstHourMetrics` | `true` | On, a first metrics row is written immediately so the post has a reading before the platform reports. Clearly marked as an early estimate. |
| `writeLineage` | `true` | On, the post is linked back to its idea and forward from its source item, which is what makes a trace possible. |
