# SpongeBob — Content Agent · Platform copy, grounded in the Knowledge Base

- **Id**: `caption`
- **Stage**: `create`
- **Hands off to**: `image`
- **Skills**: 10
- **Handlers**: `server/src/agents/caption/handlers.ts`

Writes the post. Retrieves the Knowledge Base entries for the originating hashtag and uses them as the grounding for the model call, builds the caption through the nine-stage structure, adapts it per platform, and passes the result through the brand-voice enforcer unconditionally.

## Skills

### `generation.caption.mode`

Decides whether this post is written long-form, as a short observation, or as a carousel script, and whether a model or the template writer produces it.

| Knob | Default | Description |
|---|---|---|
| `mode` | `Auto` | Auto follows the recommended format. The others force one shape regardless of what the Analysis Agent suggested. |
| `preferModel` | `true` | Off forces the deterministic template writer even when Google Cloud is configured. The output shape is identical either way. |

### `generation.caption.voice`

Retrieves the active Knowledge Base entries for this topic and its originating hashtag. Those entries are the grounding for the model call, not decoration.

| Knob | Default | Description |
|---|---|---|
| `maxEntries` | `6` | How many Knowledge Base entries are put in front of the writer. More grounding means more accurate claims and a longer prompt. |
| `requireGrounding` | `false` | On, a topic with no active entries is skipped rather than written from nothing. Off writes anyway and the compliance check reports it as unverifiable. |
| `minEntryConfidence` | `0` | Filters the grounding set by confidence. Zero uses everything active, including single-source entries. |

### `generation.caption.hook`

Writes the first line — the one thing that decides whether the rest is read — within the declared word ceiling.

| Knob | Default | Description |
|---|---|---|
| `temperature` | `55` | How much latitude the model has when writing the first line. Lower is flatter and more repeatable; higher varies the phrasing between posts, which is what stops two posts on neighbouring topics reading identically. The brand rules are enforced after generation either way, so this cannot loosen them. |
| `maxWords` | `18` | The hard ceiling on the first line. Beyond this it stops being a hook and becomes a sentence. |
| `style` | `Declarative` | Declarative states the finding. Contrarian pushes against consensus. Question invites, and underperforms for this audience. |
| `banClickbait` | `true` | Blocks "you won’t believe", numbered listicle openers and curiosity-gap constructions. |

### `generation.caption.problem`

Names the actual difficulty the post addresses, so the reader knows why the rest matters.

| Knob | Default | Description |
|---|---|---|
| `temperature` | `55` | How much latitude the model has when writing the problem section. Lower is flatter and more repeatable; higher varies the phrasing between posts, which is what stops two posts on neighbouring topics reading identically. The brand rules are enforced after generation either way, so this cannot loosen them. |
| `maxSentences` | `3` | How long the problem statement may run before it starts competing with the explanation. |
| `quantify` | `true` | On, the problem carries a number wherever the grounding supports one. |

### `generation.caption.explanation`

The body of the post: the reframe, the mechanism and the evidence. This is the step that calls the language model when one is configured.

| Knob | Default | Description |
|---|---|---|
| `temperature` | `60` | How much the model is allowed to vary its phrasing. Lower is more predictable and flatter; higher risks drifting off the grounding. |
| `maxOutputTokens` | `2048` | The token ceiling on the model response. Long enough for a full nine-stage post. |
| `layers` | `3` | How many distinct beats the body works through — reframe, mechanism, evidence by default. |
| `citeGrounding` | `true` | On, the body names where a claim came from. This is what makes invariant 26 pass, and rule 6 with it. |

### `generation.caption.close`

Ends the post with the implication and the Ethara connection, without a sales call to action.

| Knob | Default | Description |
|---|---|---|
| `temperature` | `55` | How much latitude the model has when writing the closing line. Lower is flatter and more repeatable; higher varies the phrasing between posts, which is what stops two posts on neighbouring topics reading identically. The brand rules are enforced after generation either way, so this cannot loosen them. |
| `closeStyle` | `Open question` | How the post ends. Rule 8 names this stage "closing line or question". An open question is the default because it ends by asking the audience something they can answer from their own work, rather than telling them what to conclude — and when it is selected the result is validated to actually be a question, not merely intended as one. Implication and Forward look end on a statement. None omits the close entirely. |
| `bannedCta` | `true` | Keeps "book a demo" and its relatives out of the close. This is a research account, not a funnel. |

### `generation.caption.hashtags`

Derives the topical hashtag block from the post’s own subject, never from a reach list.

| Knob | Default | Description |
|---|---|---|
| `count` | `4` | How many hashtags to derive. The brand ceiling of five is absolute and no value here can exceed it. |
| `useSourceHashtag` | `true` | On, the hashtag that surfaced this trend is always one of the tags, which keeps lineage visible on the post itself. |

### `generation.caption.adapt`

Reshapes the caption for its platform — length, line breaks and density — without changing what it claims.

| Knob | Default | Description |
|---|---|---|
| `linkedinMaxChars` | `2400` | Where the LinkedIn caption is cut. The platform truncates around 1,300 with a "see more", so the opening matters most. |
| `instagramMaxChars` | `1600` | Where the Instagram caption is cut. |
| `xMaxChars` | `280` | Where the X post is cut. At 280 the nine-stage structure compresses to hook, evidence and implication. |
| `facebookMaxChars` | `2000` | Where a Facebook caption is cut. Facebook permits far more, but engagement on long-form research posts falls off well before that. |
| `preserveLineBreaks` | `true` | On, the paragraph rhythm survives adaptation, which materially affects LinkedIn readability. |

### `generation.caption.variants`

Writes alternative phrasings of the same claim, so the operator can choose rather than only regenerate.

| Knob | Default | Description |
|---|---|---|
| `count` | `2` | How many alternatives to offer alongside the primary caption. Each is an extra model call. |
| `minDivergence` | `25` | How different a variant must be from the primary to be worth showing. |

### `generation.caption.sourceLink`

Adds the citation the caption rests on, where the platform and the grounding both support one.

| Knob | Default | Description |
|---|---|---|
| `enabled` | `true` | Off, citations stay in the Knowledge Base and never appear on the post. |
| `placement` | `End of post` | LinkedIn suppresses reach on posts with outbound links in the body, so end of post or first comment is usually right. |
